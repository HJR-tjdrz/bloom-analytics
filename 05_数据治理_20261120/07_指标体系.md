## 三、使用建议

- **看板**：优先展示复合指标（客单价、毛利率、复购率），它们才是决策依据；
- **诊断**：先用原子指标定位（订单少了还是客单价降了），再看派生指标找原因；
- **口径变更**：任何公式修改必须走 Git 评审，禁止在看板 SQL 里私自改口径。
