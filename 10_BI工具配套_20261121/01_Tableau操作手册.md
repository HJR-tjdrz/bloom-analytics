# Tableau 操作手册

> 目标：用导出的 CSV（或直连 MySQL）在 Tableau Desktop 里复刻出 4 张工作表 + 1 个仪表板。
> 全程约 20 分钟，不需要写代码。

---

## 一、连接数据

### 方式 A：连接 CSV（最简单）

1. Tableau → 连接 → **文本文件** → 选择 `10_BI工具配套_20261121/data/ads_kpi_monthly.csv`
2. 左下角「新建联合」或直接右键数据源 → **添加更多表**，把 `dim_date.csv` 也加进来
3. 两张表建立关系：`ads_kpi_monthly.month_key` = `dim_date.year_month`（字符串对字符串）

> 关系（Relationship）比旧的"连接（Join）"更安全：不会因为一对多而放大行数。

### 方式 B：直连 MySQL

1. Tableau → 连接 → **MySQL**
2. 服务器 `127.0.0.1`，端口 `3306`，数据库 `bloom_dw`
3. 账号密码见项目根目录 `.env`（`MYSQL_USER` / `MYSQL_PASSWORD`）
4. 把 `ads_kpi_monthly` 和 `dim_date` 拖进画布，建立同样的关系

## 二、四张工作表

### 工作表 1：月度 GMV 趋势（双轴：柱 + 同比折线）

| 位置 | 字段 |
| --- | --- |
| 列 | `dim_date.year_month`（设为**离散**） |
| 行 | `ads_kpi_monthly.gmv`（聚合 SUM） |

步骤：

1. 把 `gmv` 拖到行，右键 → **快速表计算 → 年同比增长**（或自己写计算字段，见下）
2. 把 `MONTH` 拖到颜色，做成 2025/2026 两条柱
3. 右键第二个 `gmv` 轴 → **双轴**，图形改为「线」
4. 格式化：数字格式 `#,##0,,"万"`，坐标轴标题改为「GMV（万元）」

**计算字段（同比增长）**：

```tableau
(SUM([Gmv]) - LOOKUP(SUM([Gmv]), -12)) / LOOKUP(SUM([Gmv]), -12)
```

> 计算依据设为「表（横穿）」，方向按 `year_month` 升序。

### 工作表 2：节日效应（条形图）

| 位置 | 字段 |
| --- | --- |
| 行 | `dim_date.festival_name` |
| 列 | `AVG([Gmv])` 或 `SUM([Gmv]) / COUNTD([Full Date])` |

步骤：

1. 筛选 `is_festival = 1` 且 `festival_name` 非空
2. 按日均 GMV 降序排列
3. 颜色用「日均 GMV」渐变（红 = 高）
4. 加参考线：`AVG([Gmv])`（全量日均），标注「平日基线」

### 工作表 3：RFM 八分群

| 位置 | 字段 |
| --- | --- |
| 列 | `rfm_segment` |
| 行 | `COUNT([customer])` + `SUM([Gmv])` |

步骤：

1. 用 `ads_customer_rfm_segments.csv`（已聚合好的 8 行）
2. 双轴条形图：人数 vs 消费额（分别用两个度量轴）
3. 或者做成**散点**：X = 平均频次、Y = 平均 R、大小 = 消费额

**计算字段（消费额占比）**：

```tableau
SUM([Gmv]) / TOTAL(SUM([Gmv]))
```

### 工作表 4：波士顿矩阵（散点图）

| 位置 | 字段 |
| --- | --- |
| 列 | `sales_amt`（连续） |
| 行 | `growth_rate`（连续，需 ×100） |
| 详细信息 | `product_name` |
| 大小 | `sales_amt` |
| 颜色 | `bcg_class` |

步骤：

1. 用 `ads_product_performance.csv`
2. 加两条参考线：X 轴 = 中位数销售额、Y 轴 = 0
3. 标记类型选「圆」，开启标签（只显示 TOP10，用筛选器控制）

## 三、仪表板拼装

1. 新建仪表板，尺寸设为 **1366 × 900**（笔记本常见分辨率）
2. 布局：
   ```
   ┌──────────────────────────────────────────┐
   │ 标题栏：花店经营分析 · 2024-2026          │
   ├────────────┬────────────┬────────────────┤
   │ KPI 卡 1   │ KPI 卡 2   │ KPI 卡 3       │  ← 用「文本」对象 + 度量
   ├────────────┴────────────┴────────────────┤
   │  月度 GMV 趋势（工作表 1，占 2/3 宽）      │
   ├─────────────────────┬────────────────────┤
   │ 节日效应（工作表 2） │ 渠道结构（饼图）    │
   ├─────────────────────┴────────────────────┤
   │ RFM 分群（工作表 3） │ 波士顿矩阵（工作表 4）│
   └──────────────────────────────────────────┘
   ```
3. 四张工作表都加 **筛选器动作**：点击某个分群 → 其它图联动过滤
4. 底部放「数据说明」文本框：口径 + 数据周期 + 生成时间

## 四、KPI 卡做法（Tableau 里没有现成卡片）

1. 新建一个工作表，只放一个度量（如 `SUM([Gmv])`）
2. 标记卡改成「文本」，把度量拖到「文本」
3. 关闭行/列标题、隐藏边框
4. 拖到仪表板，调成 200×100 的小卡片
5. 同理做「订单数」「客单价」「毛利率」「退款率」「预测 MAPE」

> 想更精致：用「容器 + 背景色」，或在标题里用 `<GMV>` 参数化文本。

## 五、常见坑

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 行数突然翻倍 | 用了 Join 而非 Relationship，且维表一对多 | 改用关系；或先去重维表 |
| 同比算出来是 null | 表计算方向/分区设错 | 计算依据选「表（横穿）」，分区按年份 |
| 中文变方块 | CSV 编码或字体问题 | 确认用 `utf-8-sig` 的 CSV；仪表板字体设为「微软雅黑」 |
| 数字带一堆小数 | 度量格式没设 | 右键度量 → 默认属性 → 数字格式 |
| 日期识别成字符串 | `month_key` 是 `2026-05` 文本 | 用 `full_date` 建日期维，或 `DATE("2026-05" + "-01")` |

## 六、导出与交付

- **打包工作簿**：文件 → 导出打包工作簿（.twbx，含数据）→ 可直接发给别人打开
- **导出图片**：仪表板 → 导出图像（PNG，建议 2× 分辨率）
- **发布**：Tableau Public（免费）可生成在线链接，适合放简历

> 简历里建议写：「使用 Tableau 复刻同一套指标体系，验证了 BI 工具与自建看板的口径一致性」。
