# 看板使用说明

## 一、打开方式

**方式 A：双击运行（推荐）**

```
H:\花店订单管理应用\最新项目\08_可视化看板_20261121\90_run_dashboard.bat
```

会自动做三件事：启动 Flask 服务（新开一个命令行窗口）→ 等 5 秒 → 用默认浏览器打开
`http://127.0.0.1:5050`。

> 那个黑窗口就是服务进程，**关掉窗口 = 停止服务**。

**方式 B：命令行**

```bash
cd H:\花店订单管理应用\最新项目
.venv\Scripts\python.exe run.py dashboard --port 5050
# 浏览器访问 http://127.0.0.1:5050
```

## 二、六个页面怎么读

### 1. 经营总览

- **顶部 6 张 KPI 卡**：GMV、订单数、客单价、成交客户、毛利额、退款率。
  每张卡的副标题都会带一个"解释性指标"（如客单价卡下面给件单价）。
- **月度 GMV 与同比**：柱子是每月 GMV（万元），折线是 2026 对 2025 的同比。
  看两个峰（2 月情人节、5 月 520+母亲节）和一个谷（7 月）。
- **渠道结构环图**：各渠道 GMV 占比，鼠标悬停看金额。
- **节日效应**：节日期间**日均** GMV。超过 4 万的用红柱（情人节级别），
  2.5 万以上用橙柱，其余蓝柱——一眼看出哪个节日值得压重注。
- **门店 GMV**：同一城市内的门店差距，是店长考核的起点。

### 2. 用户价值

- 顶部 4 张卡：客户总数、核心客户占比、核心客户 GMV 占比、挽留类 GMV 占比。
- **八分群对比**：灰柱是人数占比、蓝柱是消费额占比。
  两者差距越大，说明这个群体"人少但值钱"（或反过来）。
- **客户散点**：横轴购买频次（最多显示 30 次），纵轴最近购买天数（越靠上越久没来）。
  点越大消费越高。左上角是"曾经活跃、现在沉默"的召回重点。
- **分群明细表**：可直接拿去圈人（例如"重要保持客户 + 平均R>300天"）。

### 3. 商品结构

- **ABC 帕累托**：柱是销售额，橙线是累计占比，虚线标在 80% 处。
  柱子在第 24 根左右跨过 80% —— 这就是"24 个商品贡献 80% 销售额"的由来。
- **波士顿矩阵**：四个颜色对应明星 / 金牛 / 问题 / 瘦狗，
  气泡大小 = 销售额，横轴销售额、纵轴同比增长。
  右上角（高销售 + 高增长）是明星，右下角（高销售 + 负增长）要警惕。
- **TOP20 明细**：带 ABC / BCG 标签，可直接筛出"该砍的 C 类瘦狗"。

### 4. 促销与渠道

- **活动让利效率**：横条是 GMV，条尾标注"效率 X"（每让 1 元折扣换回多少毛利）。
  效率高的活动值得复用，效率低的要停。
- **折扣敏感度**：柱是各折扣区间的订单占比，红线是毛利率。
  如果深折扣区间的柱子没有明显变高，说明"打折拉不动量"。
- **渠道效率气泡**：横轴客单价、纵轴佣金后净利率、气泡大小 GMV。
  右上角是理想渠道，左下角是"又便宜又抽成高"的渠道。
- **渠道明细表**：能看到美团 18% 佣金吃掉多少利润。

### 5. 库存损耗

- **品类周转与损耗**：柱是周转天数（越低越好），红线是损耗率（越低越好）。
  柱子高 + 红线高的品类是重点整改对象（本项目是绣球）。
- **滞销 TOP10**：C 类里销量垫底的商品，建议下架或清库存。

### 6. 销售预测

- 顶部：回测 MAPE、未来 30 天预测合计、预测峰值日。
- **预测曲线**：蓝线是近 90 天实际，红线是未来 30 天预测，
  两条虚线是 80% 置信区间的上下界。
- **预测明细表**：逐日给出预测值与区间，可直接用于排班与备货。

## 三、筛选器怎么用

- 筛选器（日期区间 / 渠道 / 门店）**只对「经营总览」生效**，因为其它页读的是预计算结果；
- 切到其它页时，筛选栏会自动置灰，右上角出现「全量口径」徽标；
- 点「应用筛选」后回到总览页会重新计算（约 1~2 秒，之后 5 分钟内走缓存）；
- 点「重置」恢复全量区间。

## 五、常见问题

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 打开是空白页 | 服务没起来 / 端口被占 | 看那个黑窗口有没有报错；换端口 `run.py dashboard --port 5051` |
| 图表全是 0 / 空 | `ads_*` 结果表没数据 | 先跑 `python run.py analysis` |
| 页面能开但数据报错 500 | MySQL 没启动 | 启动 MySQL 服务后刷新（缓存 5 分钟，急的话重启服务） |
| 字体变成方块 | 系统缺中文字体（极少见） | Windows 自带微软雅黑，一般不会出现 |
| 端口 5050 被占用 | 有别的程序在用 | 换端口启动，或在 bat 里改 `--port` |

## 六、性能小贴士

- 首次打开「经营总览」约 **1.8 秒**（要扫 11.6 万行事实表），之后 5 分钟内都是毫秒级；
- 其它页面首次打开 60~370 毫秒（读预计算表）；
- 页面切换是懒加载的，第一次点某个 Tab 才渲染，之后只是显示/隐藏。
